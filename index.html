Authentication Protocol

Every piece is verifiable.
Always.

01 — HASH
Three SHA-256 hashes

Garment spec, artwork file, and metadata record — each independently hashed at production time.

02 — MARK
Creator mark + Artifact ID

CA-AI-CHUNK-0001. CAC-MARK-001. Printed on the interior label. Registered on release.

03 — VERIFY
Scan or look it up

QR on the garment or manual ID entry. The static registry returns the full authenticated record instantly.

04 — PERMANENT
The record outlives the brand

Plain JSON. No proprietary tooling. No database. Anyone with a browser can verify this.
